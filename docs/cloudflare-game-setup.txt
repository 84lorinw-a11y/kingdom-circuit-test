What the build does
- Runs the existing manifest/inventory/approved-art/game-isolation verifier.
- Rewrites the GitHub Pages prefix to /play/ for the new hostname.
- Gives media a content-derived directory name so it can be cached for a year
  without serving stale artwork when a media file changes.
- Revalidates small HTML, CSS and JS files so fixes arrive on returning visits.
- Preserves the silent video, device-only score service and all ten games.
- Adds root redirect, real 404 page, noindex/robots rules and response headers.
- Rejects unexpected files and files over Cloudflare's 25 MiB per-file limit.
- Includes no credentials, source reports, source repository, or server code.

Current limits and next work
The complete package is about 22.14 MB; its largest file is the 3.72 MB silent
video. Packaging alone does not reduce the 11.55 MB of images loaded at entry.
Next: show character selection first, load the exterior next, and defer stage
and VIP assets until needed. Do not claim a faster first load until measured.

Browser saves are scoped to the hostname. A player's GitHub TEST save will not
automatically appear on a new pages.dev/custom-domain URL. Scores are local to
that device; Cloudflare static hosting does not create a shared leaderboard.

Cloudflare account capacity and a 100K-player traffic spike have not been tested.
No billing plan, spend commitment, domain transfer or new global score backend
has been authorized/configured by this package. Review those separately before
a large public launch. Future larger media can use R2 with a cached custom domain;
do not use the rate-limited r2.dev endpoint for a production media launch.
